# Dental Clinic Presentation

A static, multilingual website template for a dental clinic. It includes English, Italian, and Albanian text, with pages for services, the team, reviews, pricing, and contact details.

## View it locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript; there is no build step.

The clinic name, address, phone number, staff, reviews, prices, and service details are sample content. Replace and verify them before publishing. The contact form is a demo and does not send messages until you connect a form service.
